# 매출 합산 규칙 (지금까지 안내된 내용)

## 합산 대상 컬럼
- 합산할 컬럼은 **헤더 이름이 정확히 `amount`**인 컬럼이다. 컬럼 위치(인덱스)로 찾지 말 것 —
  파일마다 컬럼 순서가 다르다(`data/` 안의 샘플들을 열어보면 순서가 서로 다른 걸 확인할 수 있다).

## 구분자
- 구분자는 확장자로 판단한다: `.csv` = 콤마(`,`), `.tsv` = 탭(`\t`), `.psv` = 파이프(`|`).

## 출력 형식
- 표준출력(stdout)에 **JSON 한 줄**만 출력한다. 필드 이름은 반드시 아래 이름 그대로 사용한다:
  ```json
  { "total": 0, "counted": 0, "skipped": 0 }
  ```

(이 문서는 요구사항이 추가될 때마다 계속 갱신된다 — 항상 최신 버전을 기준으로 봐라.)
