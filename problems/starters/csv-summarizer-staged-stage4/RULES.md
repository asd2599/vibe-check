# 매출 합산 규칙 (최종본 — 모든 단계 요구사항 반영)

## 합산 대상 컬럼
- 합산할 컬럼은 **헤더 이름이 정확히 `amount`**인 컬럼이다. 컬럼 위치(인덱스)로 찾지 말 것 —
  파일마다 컬럼 순서가 다르다.
- 헤더 행이 없거나 `amount` 컬럼이 없는 파일은 처리 대상이 아니다(이 경우 정확히 어떤 출력을
  내야 하는지는 이 문서에서 정하지 않는다 — 합리적으로 판단해서 처리할 것).

## 구분자
- 구분자는 확장자로 판단한다: `.csv` = 콤마(`,`), `.tsv` = 탭(`\t`), `.psv` = 파이프(`|`).

## 따옴표 규칙 (RFC 4180 준용)
- 칸(field)은 큰따옴표(`"`)로 감쌀 수 있고, 감싼 칸 안에는 구분자(콤마/탭/파이프)와 개행이
  그대로 포함될 수 있다 — 이 경우 구분자로 분리하면 안 된다.
- 감싼 칸 안에서 큰따옴표 자체를 표현하려면 `""`(큰따옴표 두 개)로 이스케이프한다.

## 유효 금액 판정
- 유효한 금액 = 선택적 부호(`-`) + 숫자 1개 이상 + 선택적 소수점 이하 숫자.
- **천단위 구분 쉼표(예: `1,200`)는 제거한 뒤 유효한 숫자로 처리**한다 (`1,200` → `1200`).
- 음수(예: `-500`, 환불/차감 건)는 **합산에 포함**한다. 부호만 있고 숫자가 없는 값(`-` 단독)은
  무효로 취급한다.
- 그 외 값(빈 칸, 문자가 섞인 값, 통화 기호가 포함된 값 — 예: `N/A`, `-`, `TBD`, `₩1,200`, `$50`)은
  전부 **건너뛴다(skip)**.

## 출력 형식
- 표준출력(stdout)에 **JSON 한 줄**만 출력한다. 필드 이름은 반드시 아래 이름 그대로 사용한다:
  ```json
  { "total": 0, "counted": 0, "skipped": 0 }
  ```
  - `total`: 유효한 금액들의 합계. **소수점 셋째 자리에서 반올림**(반올림 방식은 "0.005는 올림"하는
    반올림 — 즉 정확히 경계값이면 항상 위로 올린다)해서 소수점 둘째 자리까지의 숫자로 낸다.
  - `counted`: 합산에 포함된(유효한) 데이터 행 수.
  - `skipped`: 건너뛴(무효한) 데이터 행 수.
  - 헤더 행은 `counted`/`skipped` 어느 쪽에도 세지 않는다.

(이게 마지막 갱신본이다 — 더 이상 바뀔 요구사항은 없다.)
